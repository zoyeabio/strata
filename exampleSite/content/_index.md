A content-first Hugo theme for independent sites. One theme, many brands,
every image responsive, and no implicit external requests in the head.

This is the theme's own example site. Each page below exists to exercise a
real feature rather than to sell one, so the content is deliberately
thin and the markup is the point.

## What a theme should get right

Strata takes a small number of positions and holds them. Copy is the
product, so the reading column stays narrow and the prose styles stay out
of your way. Images resolve to a responsive ladder at build time, so the
same source serves a phone and a wall of 4K without a separate asset.
Social cards and JSON-LD are generated from the same resolved image a page
actually shows, so a share preview never lies.

Nothing in the head is remote. No web font, no analytics, no third-party
script. The one sanctioned exception is AdSense, and only on a page that
carries an ad unit.
