{{- /* Previous / next navigation to the neighbouring articles of the current section. Takes a page, not a paginator: {{ partial "page/neighbors.html" . }}. Hugo sorts the neighbours by date, so PrevInSection is the older article and NextInSection the newer one — the left link goes back, the right link goes on. Gated by site.Params.article.showPagination (default true), overridable per page as showpagination. A lone article prints nothing rather than an empty bar. Called by: _default/single.html, already guarded to article pages only. */ -}} {{- $art := site.Params.article }} {{- $show := $art.showPagination }} {{- if isset .Params "showpagination" }}{{ $show = .Params.showpagination }}{{ end }} {{- if $show }} {{- if or .PrevInSection .NextInSection }}
{{- with .PrevInSection }} ← Previous article {{ .Title | emojify }} {{- end }} {{- with .NextInSection }} Next article → {{ .Title | emojify }} {{- end }}
{{- end }} {{- end }}
