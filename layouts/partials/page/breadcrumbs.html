{{- /* Ancestor trail: Home / section / … . Ancestors only — the current page is the H1 beside the trail, so repeating it here is a crumb with no destination. Hidden when nothing sits above Home: a top-level section or taxonomy page is already announced by the highlighted menu entry and its own H1, and a trail of just "Home" would be decoration. The first crumb that earns the trail is the child of such a page. A crumb's label is its menu name when the page is in any menu — the same short label the navigation shows — falling back to LinkTitle. Without this a section titled "Probiotic Strains and Prebiotic Fiber Ingredients" would ship that whole string as a single crumb. Matched against both the relative and the baseURL-prefixed URL, since Hugo resolves a menu URL to one or the other depending on how baseURL is set. Visibility is the page's own showBreadcrumbs when set (isset, so an explicit false wins), otherwise the table matching its Kind: article, list, taxonomy, term. All default to hidden. Called by: _default/single.html, list.html, terms.html, term.html */ -}} {{- $table := dict }} {{- if eq .Kind "page" }}{{ $table = site.Params.article }} {{- else if in (slice "section" "home") .Kind }}{{ $table = site.Params.list }} {{- else if eq .Kind "taxonomy" }}{{ $table = site.Params.taxonomy }} {{- else if eq .Kind "term" }}{{ $table = site.Params.term }}{{ end }} {{- $show := $table.showBreadcrumbs }} {{- if isset .Params "showbreadcrumbs" }}{{ $show = .Params.showbreadcrumbs }}{{ end }} {{- $ancestors := slice }} {{- $p := .Parent }} {{- range seq 10 }}{{ if and $p (not $p.IsHome) }}{{ $ancestors = $ancestors | append $p }}{{ $p = $p.Parent }}{{ end }}{{ end }} {{- if and $show $ancestors }}
  1. Home
    2. {{- range $ancestors | collections.Reverse }} {{- $crumb := . }} {{- $label := $crumb.LinkTitle }} {{- range $menu := site.Menus }}{{ range $entry := $menu }}{{ if and $entry.URL (or (eq $entry.URL $crumb.RelPermalink) (eq $entry.URL (printf "%s%s" site.BaseURL $crumb.RelPermalink))) }}{{ $label = $entry.Name }}{{ end }}{{ end }}{{ end }}
  2. {{ $label }}
    3. {{- end }}
{{- end }}
