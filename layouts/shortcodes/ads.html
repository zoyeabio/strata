{{- /* AdSense display unit. The loader script ships in head only on pages that use this shortcode, so sites without ads pay nothing. Parameters slot (string, required) — the ad slot ID from the AdSense dashboard format (string, optional) — data-ad-format, default "auto" minHeight (string, optional) — reserve vertical space up front (e.g. "250px") so the ad iframe cannot shift layout (CLS) Site config [ads] client (string, required) — the "ca-pub-…" publisher ID. Missing client stops the build. Pages carrying a unit must also ship static/ads.txt naming the ID (check-build R11 enforces it). The unit must sit directly in markdown: shortcodes composed inside a partial are invisible to the head loader check (.HasShortcode reads page source only), so a shared ad block belongs in a snippet authors paste, not a partial. The push call lives in js/ads.js behind an integrity attribute — the same pattern as contact.js and carousel.js — so enabling ads never asks static/_headers for unsafe-inline. The loader itself is the one sanctioned cross-origin request, and head.html fails the build when the Content-Security-Policy would block it. Called by: content markdown */ -}} {{- $client := site.Params.ads.client -}} {{- if eq $client "" -}} {{- errorf "ads shortcode: site.Params.ads.client is not set (%s)" .Position -}} {{- end -}} {{- $slot := .Get "slot" -}} {{- if not $slot -}} {{- errorf "ads shortcode: requires slot, e.g. {{< ads slot=\"1234567890\" >}} (%s)" .Position -}} {{- end -}} {{- with resources.Get "js/ads.js" }} {{- $js := . | fingerprint "sha512" }} {{- end }}
