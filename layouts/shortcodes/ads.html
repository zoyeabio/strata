{{- /* AdSense display unit. With `[ads] consent = "none"` the loader script ships from head on pages that use this shortcode; `[ads] auto = true` ships it site-wide without any unit placed, so sites without neither set up pay nothing. Parameters slot (string, required) — the ad slot ID from the AdSense dashboard format (string, optional) — data-ad-format, default "auto" minHeight (string, optional) — reserve vertical space up front (e.g. "250px") so the ad iframe cannot shift layout (CLS) Site config [ads] client (string, required) — the "ca-pub-…" publisher ID, shape-checked here and in head.html so a malformed ID fails the build instead of reaching Google as a garbage loader URL. Missing client stops the build. Pages carrying a unit must also ship static/ads.txt naming the ID (check-build R11 enforces it). The unit must sit directly in markdown: shortcodes composed inside a partial are invisible to the head loader check (.HasShortcode reads page source only), so a shared ad block belongs in a snippet authors paste, not a partial. The push call lives in js/ads.js behind an integrity attribute — the same pattern as contact.js and carousel.js — so enabling ads never asks static/_headers for unsafe-inline. The loader itself is the one sanctioned cross-origin request, and head.html fails the build when the Content-Security-Policy would block it. The script copy also carries the site's [ads] consent value; under "gated" this same file delays the loader until the site's consent answer is granted. Called by: content markdown */ -}} {{- if ne .Page.Params.ads false -}} {{- $client := site.Params.ads.client -}} {{- $consent := site.Params.ads.consent | default "none" }} {{- if eq $client "" -}} {{- errorf "ads shortcode: site.Params.ads.client is not set (%s)" .Position -}} {{- end -}} {{- $slot := .Get "slot" -}} {{- if not $slot -}} {{- errorf "ads shortcode: requires slot, e.g. {{< ads slot=\"1234567890\" >}} (%s)" .Position -}} {{- else if not (findRE `^\d+$` $slot) -}} {{- errorf "ads shortcode: slot %q is not the numeric ID from the AdSense dashboard (%s)" $slot .Position -}} {{- end -}} {{- if not (findRE `^ca-pub-\d{16}$` $client) -}} {{- errorf "ads shortcode: client %q does not look like a ca-pub-… publisher ID (that is ca-, then pub-, then 16 digits — AdSense for Platforms' ca-host-pub-… belongs in data-ad-host, never here); fix site.Params.ads.client (%s)" $client .Position -}} {{- end -}} {{- with resources.Get "js/ads.js" }} {{- $js := . | fingerprint "sha512" }} {{- end }} {{- end }}
